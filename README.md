# Ardhi field boundary tiles, second repository

Field boundary tiles (PMTiles) for ARDHI 1 that do not fit in [ardhi-fields](https://github.com/HarambeeAI/ardhi-fields), which is near the size limit of GitHub Pages.

The files here are listed, by their full address, in the one list of layers the app reads: https://harambeeai.github.io/ardhi-fields/manifest.json. See the README of ardhi-fields for what the layers are, how they were made and the terms of use.

| File | Area | Fields |
|---|---|---|
| `kenya_c_1.pmtiles`, `kenya_c_2.pmtiles` | South-eastern Kenya: Kitui, Makueni, Taita-Taveta and the southern coast (about 38.1 to 40.2 E, 0.0 to 4.7 S); 13 of the 89 Sentinel-2 tiles of Kenya, built 18 November 2026 | 2,876,431 |
